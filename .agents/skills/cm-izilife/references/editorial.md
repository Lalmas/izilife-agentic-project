# Editorial rules

## Caption vs visual

The visual must communicate the hook quickly.

The caption may:
- expand the context;
- invite conversation;
- add hashtags;
- provide details that would overload the image.

Never paste the full caption into the image.

## Factual content

Do not invent:
- dates;
- prices;
- artists;
- event times;
- venue facts;
- historical facts;
- offers.

When factual content is missing, stay generic or ask for the missing fact if it blocks production.

## French

All final French text must be proofread.

Required:
- accents;
- correct apostrophes;
- sentence capitals;
- correct punctuation;
- natural French phrasing.

For imposed visual text, preserve wording and correct only obvious formatting/encoding defects unless the user authorizes rewriting.

## Revisions

Preserve approved decisions.

A revision is a delta, not a reset.

If the user prefers version B, version B becomes the new working reference.
