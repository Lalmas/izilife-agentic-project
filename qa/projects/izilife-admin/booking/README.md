# QA BO Booking

Contrôler la création et modification des mêmes données métier que le Partner Space, sans imposer sa structure visuelle : catégorie unique ou groupée, BC/BCC, segments, politique d'acceptation et conditions de privatisation.

Le BO ne copie pas les vues PS. Le scénario `BO-BOOKING-CONFIG` vérifie seulement que l'administrateur peut renseigner, à la place du partenaire, chaque configuration portée par les cartes/formulaires BO existants.
