## Positionnement fondamental

izilife n'est PAS un influenceur. izilife EST un agrégateur.

La force : organiser ce qui existe déjà — événements, lieux, acteurs locaux,
influenceurs, communautés — et devenir le point d'entrée de la vie sociale locale.

Google n'a pas créé les sites. Booking n'a pas créé les hôtels.
izilife n'a pas à créer le contenu. izilife l'organise.

Le compte Instagram n'est PAS le produit.
Le site izilife EST le produit.
Instagram / Facebook / TikTok / terrain physique = canaux qui ramènent vers le site.

---

## Ce qu'on ne fait PAS

- Vidéos "viens voir ce resto / ce lieu"
- Réels classiques à la mode
- Interviews de lieux
- Concurrencer les influenceurs sur leur terrain
- Posts génériques "Que faire à Lille ce week-end" → le site le fait 10x mieux automatiquement
- Laisser l'IA décider qui mérite d'être dans les tops → c'est toujours le fondateur qui choisit

## Les 5 piliers éditoriaux

### Pilier 1 — AGENDA
Fréquence : 2x/semaine (lundi + jeudi)
Format : Story principalement
- Lundi : agenda de la semaine → "Cette semaine à Lille 📅"
- Jeudi : sélection week-end → "Ce week-end c'est ça 🔥"
- CTA systématique : "Voir les 200 événements → lien en bio"
- Temps forts : Braderie, vacances scolaires, LDC, Fête de la Musique...
Objectif : Habituer les gens à venir sur izilife pour l'agenda complet.

### Pilier 2 — TOPS & DÉCOUVERTES
Fréquence : 1-2x/semaine
Format : Carrousel (style izilife — templates Canva existants)
Contenu : Tops de tout ce qui fait vivre la ville.
IMPORTANT : Le fondateur fournit toujours la liste dans la colonne ARTISTE/DJ/ASSO du planning.
L'agent ne choisit PAS qui mettre dans un top — il met en forme ce qu'on lui donne.
- Lieux : bars ambiance, bars 1ère/2ème partie, rooftops, terrasses, brunchs...
- Acteurs : influenceurs food, TikTokeurs, DJs, collectifs, médias locaux...
- Communautés : groupes sport, écoles de danse, clubs de lecture, assos...
CTA : "Retrouve-les tous sur izilife"

### Pilier 3 — HISTOIRE & HUMOUR LOCAL
Fréquence : 1x/semaine (alterner histoire/humour semaine sur semaine)
Format : Post image ou carrousel

HISTOIRE_LIEU :
- L'origine de la Braderie de Lille
- La Citadelle : ce que les Lillois ne savent pas
- Les géants du Nord, la Grand-Place, les estaminets...
Ton : passionné, ancré, pas Wikipédia. 5-8 phrases max. Accroche inattendue.

HUMOUR_LOCAL :
- "Tu sais que t'es un vrai Lillois quand..."
- Sondages, clichés nordistes assumés, météo nordiste, welsh du dimanche...
Ton : complice. On se moque avec eux, jamais d'eux.

### Pilier 4 — ESCAPADES
Fréquence : 2-4x/mois
Format : Carrousel photo ou Reel court
Villes cibles : Cassel, Arras, Le Touquet, Saint-Omer, Wambrechies, Seclin,
  Tournai, Bruges, Gand, Boulogne, Montreuil-sur-Mer...
Structure d'un post ESCAPADE_VILLE :
  Slide 1 : photo accroche + "Enregistre ce post ☀️"
  Slides 2-N : 1 lieu/activité par slide avec label 📍 Nom
  Slide finale : logo izilife + CTA site
Caption : ami qui recommande. Distance depuis Lille toujours précisée.
Objectif : Niche peu saturée. Monétisable (hébergements, offices de tourisme).

### Pilier 5 — PÉPITES & NICHES
Fréquence : occasionnel
Format : Post simple ou story
Contenu : événements nichés introuvables ailleurs
- DJ set afro house, concert folk, jam session jazz
- Soirée salsa, tournoi de fléchettes, expo photo de rue
- One man show local, chorale, club de lecture
Objectif : Prouver qu'izilife voit ce que personne d'autre ne voit.

## Events — deux types distincts

### EVENT_SERIE
Events izilife récurrents (Wine Tasting, Quiz, Blind Test, Izilympics...).
Même concept, décliné par lieu + date + heure.
L'agent génère : post IG/FB + structure affiche Canva.

### EVENT_ANIMATEUR
On paie le fondateur pour animer un lieu (concert, soirée, DJ set...).
Données fournies : artiste/DJ, lieu, date, style musical, conditions d'entrée.
Peut porter la marque "Scènes izilife" si pertinent.
L'agent génère : post IG/FB + structure affiche + éventuellement story teaser.

## Stratégie terrain physique

- Flyers / stickers QR code chez les partenaires (toilettes, comptoir, vitrine)
  Message : "Retrouve tous les événements autour de toi sur izilife"
- Affichage grands parcs (Citadelle) : viser les communautés sport/danse/events
- Modèle partenariat : référencement gratuit → en échange flyer izilife chez eux
- Collage QR codes nocturne (arrêts de bus, zones festives)

---

## Ton & style

- Proche, naturel, jamais corporate
- Humour local assumé — la culture nordiste est une force
- Court et direct — pas de roman dans les captions
- 1 seul CTA par post : revenir sur izilife
- Jamais condescendant, jamais touriste
