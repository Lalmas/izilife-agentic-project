Oui. Ton projet s’articule autour d’un écosystème d’agents spécialisés branchés autour de ton application, avec une logique très pragmatique :

## Architecture générale

Tu ne veux pas :

* un “super agent magique” ;
* donner la prod entière à une IA ;
* laisser un LLM publier directement.

Tu veux :

* des agents spécialisés ;
* cloisonnés ;
* supervisés ;
* alimentant des tables temporaires ;
* avec validation humaine finale.

Tu as choisi :

* comptes de service ;
* scopes limités ;
* blocage global des comptes agents sur l’UI humaine ;
* accès uniquement à certaines méthodes autorisées.

## Ton architecture actuelle

Tu as déjà :

* tables `_tmp` ;
* pipelines scraping ;
* validation humaine ;
* scripts d’import ;
* Google Places ;
* enrichissement ;
* gestion des doublons ;
* hubs de sources.

Donc ton système est déjà semi-agentique.

## Ta philosophie sécurité

Tu refuses :

* accès complet DB ;
* accès complet code ;
* secrets ;
* `.env` ;
* publication directe ;
* suppression directe.

Tu veux :

* staging ;
* compte service ;
* scopes ;
* logs ;
* permissions minimales ;
* validation humaine.
