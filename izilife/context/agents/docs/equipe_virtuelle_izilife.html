L'équipe virtuelle izilife — agents data quality et contenu

L'orchestration — qui déclenche qui
Deux cerveaux planificateurs
OVH staging (cron) — tout ce qui ne nécessite pas de navigateur : RSS, injection JSON, rapports, appels Claude API directs
PC local (Windows Task Scheduler) — tout ce qui nécessite Chrome : CIC enrichissement, Cowork publication. Lance un script qui ouvre le bon workflow.
Les deux se synchronisent via Google Sheets (file de tâches) et les tables _tmp
L'équipe — 6 employés virtuels
