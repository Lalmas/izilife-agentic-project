Clarification des 4 outils Claude et leur consommation de tokens

Claude.ai (chatbot)
Tu parles, il répond. C'est tout.
Répond à tes questions, rédige, analyse, planifie
Cherche sur le web (outil intégré dans le chat)
Ne peut PAS agir sur ton PC, publier, cliquer, créer des fichiers
Ne peut PAS tourner en boucle la nuit tout seul
Tokens Pro 20€ : ~45 msg/jour avec Sonnet 4 (illimité en pratique pour une utilisation normale). Quota remis à zéro chaque jour. Inclus dans 20€
Claude Code
IA de dev qui s'exécute dans un terminal sur ton PC.
Lit, écrit, exécute du code (PHP, Python, JS…) sur ton PC local
Se connecte en SSH à un serveur distant (OVH), push Git
Lance des scripts, lit des fichiers, gère des projets entiers
Ne contrôle PAS un navigateur (n'ouvre pas Chrome, ne clique pas)
Ne publie PAS sur les réseaux sociaux directement
Tokens : Claude Code = terminal sur ton PC, utilise l'API Claude. Avec Pro 20€ il y a une enveloppe incluse (limites d'usage par session/mois). Si tu dépasses → facturation API séparée. Une session de dev interactive (tu poses des questions, il répond) consomme peu. Un agent autonome qui tourne en boucle 8h = beaucoup de tokens car il analyse et re-analyse en continu. Inclus Pro avec limites
Claude in Chrome
Claude voit et comprend ce que ton navigateur affiche.
Lit et comprend intelligemment n'importe quelle page web ouverte dans Chrome
Peut cliquer, remplir des formulaires, naviguer de page en page
Page Facebook event → comprend directement titre/date/lieu sans sauvegarder le HTML
Peut faire des screenshots (= tokens consommés pour analyser l'image)
Chaque page lue = tokens consommés (lecture + analyse du contenu)
Tokens : Oui, Claude in Chrome consomme des tokens à chaque page visitée — parce que Claude lit et analyse le contenu. C'est le prix de l'intelligence. Une page simple ~1 000-2 000 tokens. Une page dense (Maps, Instagram) ~3 000-5 000. Inclus Pro avec limites
Cowork
Robot qui clique sur ton PC Windows — sans comprendre.
Automatise des actions répétitives sur ton bureau Windows (ouvrir, cliquer, copier, sauvegarder)
Ouvre Chrome, va sur une URL, scrolle, clique droit → "Enregistrer sous"
Publie sur Instagram/Facebook si tu lui montres le chemin
N'est PAS intelligent — il exécute des séquences mécaniques
Ne "comprend" pas une page — il clique sur des coordonnées/sélecteurs
Tokens : Cowork lui-même est piloté par Claude (il y a un LLM derrière pour interpréter tes instructions). Donc oui, ça consomme des tokens Claude — mais beaucoup moins que Claude in Chrome car il n'analyse pas le contenu des pages. Abonnement Cowork séparé
Résumé brutal : Cowork = robot mécanique qui clique. Claude in Chrome = cerveau qui lit et comprend. Pour scraper du volume → Cowork + script PHP (économique). Pour extraire intelligemment d'une page complexe → Claude in Chrome (qualitatif mais coûteux en tokens).
