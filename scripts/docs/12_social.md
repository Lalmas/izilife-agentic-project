# 12 — Social / Community Manager

## But

Générer les textes et visuels pour les réseaux sociaux.

## Structure Drive izilife

```text
izilife/social/lille-zone/
  planning_lille-zone.xlsx
  inputs/
    post_001/
      description.txt
      image.png
  outputs/
```

## Excel

Le planning contient le contenu éditorial.

L'onglet `Post Types` contient la configuration éditoriale/template par type de post.

## Sources d'information

Le CM peut fonctionner avec :

1. Excel seul.
2. `description.txt` seul.
3. Excel + `description.txt`.

Priorité : Excel donne les instructions structurées, `description.txt` complète.

## Image

Le moteur image est configuré côté serveur, pas dans l'Excel.

Le template appartient à `Post Types`, pas à chaque ligne de planning.
