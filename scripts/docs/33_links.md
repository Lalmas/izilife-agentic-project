# 33 — Agent Links

## But

Ajouter des liens officiels ou utiles à un objet.

## Scopes

```text
page
place
shop
event
experience
annual_celebration
event_serie
circuit
local_habit
equipment
```

## Sheet

```text
izilife/links/{zone}-zone/links.xlsx
```

## Règle

- Si URL izilife fournie : le BO peut déduire le type.
- Si string_id fourni : le type/scope est obligatoire.
