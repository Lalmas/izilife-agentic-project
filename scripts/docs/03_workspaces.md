# 03 — Workspaces

## Règle

Les fichiers de travail sont sur le Drive. Les secrets et configs techniques restent côté serveur/local.

## Exemple social izilife

```text
G:/Mon Drive/agentic_workspace_local/izilife/social/lille-zone/
  planning_lille-zone.xlsx
  inputs/
  outputs/
```

## Exemple objets

```text
G:/Mon Drive/agentic_workspace_local/izilife/experiences/lille-zone/
  sources_experiences.xlsx

G:/Mon Drive/agentic_workspace_local/izilife/circuits/lille-zone/
  sources_circuits.xlsx
  curate_circuits.xlsx

G:/Mon Drive/agentic_workspace_local/izilife/links/lille-zone/
  links.xlsx

G:/Mon Drive/agentic_workspace_local/izilife/external_media/lille-zone/
  external_media.xlsx
```

```text
{zone}-zone/logs/W25/fichier_YYYY-MM-DD.xlsx
```
