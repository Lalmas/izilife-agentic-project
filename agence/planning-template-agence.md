# Planning agence — V4 simplifié

Même structure qu'izilife, mais par client.

## Onglet Planning

| Colonne | Rôle |
|---|---|
| DATE | Date de publication |
| RÉSEAU | Instagram / Facebook / Les deux |
| TYPE | Type de post client |
| VILLE | Ville si utile |
| LIEU | Lieu si utile |
| SUJET | Sujet court |
| DATA / INFOS | Offre, prix, contraintes, texte client, détails événement, témoignage |
| DATE EVENT | Date événement |
| HEURE / DURÉE | Heure ou durée |
| INPUT_ID | Dossier inputs |
| IMAGE_PROMPT | Prompt ponctuel |
| POST OUTPUT | Texte généré |
| IMAGE_OUTPUT | Image générée ou référence |
| IMAGE_STATUS | statut image |
| STATUT | À faire / Généré / Relancer / Validé / Publié / Skip |

## Onglet Post Types

La configuration visuelle stable est ici, pas dans chaque ligne.

| Colonne | Rôle |
|---|---|
| POST_TYPE | Type |
| CONTENT_TYPE | post / carrousel / story / reel / video |
| TEMPLATE_LOCAL | Dossier template client |
| TEMPLATE_SOURCE | owned / inspiration / none |
| TEMPLATE_REF | Canva ID, URL, chemin ou note |
| IMAGE_PROVIDER | canva / gpt / pillow / none |
| IMAGE_MODE | auto / template / input / generate / none |
| NOTES | Règles client |
